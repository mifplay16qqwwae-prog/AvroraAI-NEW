# AvroraAI — Автономная AI-студия 2D-мультфильмов

Полностью автоматизированная студия генерации вертикальных 2D-мультфильмов (`1080×1920`, `9:16`, `24 FPS`, MP4) на русском языке с участием **Бублика** (круглый синий герой) и **Пикселя** (оранжевый робот) и органичной рекламой **AvroraVPN**.

## Что умеет студия
1. **Сценарии через Gemini 2.5 Flash API:** Создаёт оригинальные комедийные мини-сюжеты из 3 сцен на русском языке с соблюдением лимитов бесплатного тарифа (`15 RPM / 1500 RPD`).
2. **Настоящая 2D-анимация (без слайд-шоу):**
   - Синхронизация рта (lip-sync) по реальной громкости WAV-дорожки каждого персонажа.
   - Моргание глаз, 6 эмоций (`neutral`, `happy`, `shocked`, `worried`, `smug`, `idea`).
   - Кинематика рук и ног (`idle`, `wave`, `point`, `jump`, `panic`, `walk`).
   - 5 анимированных локаций (`cyber_room`, `cafe_wifi`, `night_city`, `space_station`, `server_vault`) и плавные переходы (crossfade).
3. **Звук и озвучка:** Два разных русских голоса (`ru-RU-DmitryNeural` для Бублика и `ru-RU-SvetlanaNeural` для Пикселя), звуковые эффекты (`pop`, `whoosh`, `alert`, `chime`) и фоновая музыка с автоприглушением под речью.
4. **Автоматизация в GitHub Actions:** Запуск каждый час по расписанию (`cron`) и ручной запуск из интерфейса GitHub с сохранением готовых `.mp4`, `.srt` и `.json` в Artifacts.

## Быстрый запуск на GitHub (бесплатно)
1. Получите бесплатный API-ключ в [Google AI Studio](https://aistudio.google.com/).
2. Создайте новый репозиторий на GitHub и загрузите в него содержимое этого архива.
3. Откройте в репозитории **Settings → Secrets and variables → Actions → New repository secret**.
4. Добавьте секрет `GEMINI_API_KEY` со значением вашего ключа.
5. Перейдите во вкладку **Actions → AvroraAI Autonomous Cartoon Studio → Run workflow** для ручного запуска. Далее студия будет выпускать новую серию каждый час.

## Локальный запуск на ПК
1. Установите Python 3.10+ и **FFmpeg**.
2. Скопируйте `.env.example` в `.env` и впишите свой `GEMINI_API_KEY`.
3. Установите зависимости и запустите генерацию:
   ```bash
   pip install -r requirements.txt
   python main.py
   ```
4. Готовые файлы появятся в папке `output/ready_to_post/`.
